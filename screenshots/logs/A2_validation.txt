
$ curl -X POST /predict -d {"forecast_days":-1}
  -> HTTP 400  {"error":"Bad Request","message":"forecast_days must be between 1 and 90, got -1"}


$ curl -X POST /predict -d {"forecast_days":"seven"}
  -> HTTP 400  {"error":"Bad Request","message":"forecast_days must be a number, got str"}


$ curl -X POST /predict -d {"forecast_days":null}
  -> HTTP 400  {"error":"Bad Request","message":"forecast_days cannot be null"}

  -> HTTP 400  {"error":"Bad Request","message":"request body is not valid JSON; send a JSON object or an empty body"}

  -> HTTP 400  {"error":"Bad Request","message":"request body must be a JSON object, got list"}
